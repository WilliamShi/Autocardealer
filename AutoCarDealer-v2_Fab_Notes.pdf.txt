============================================================
PCB FABRICATION SPECIFICATION
Project: AutoCarDealer v2 Controller Board
============================================================

1. GENERAL
   - Board type        : Rigid, 2-layer, FR-4
   - Board size        : 100.0 mm x 80.0 mm (±0.2 mm)
   - Board thickness   : 1.6 mm ±10%
   - Copper weight     : 1 oz (35 µm) both sides
   - Surface finish    : HASL Lead-Free (HASL-LF)
   - Solder mask       : Green, both sides
   - Silkscreen       : White, both sides
   - Min trace width   : 0.20 mm
   - Min trace spacing : 0.20 mm
   - Min drill         : 0.30 mm
   - Min annular ring  : 0.13 mm
   - Via type          : Through-hole, tented
   - Via drill/pad     : 0.3/0.6 mm (signal), 0.5/1.0 mm (power)
   - Impedance control : Not required
   - Castellation     : None
   - Edge plating      : None

2. STACKUP
   Layer 1  Top Copper     1 oz   0.035 mm
   Layer 2  FR-4 core             1.530 mm
   Layer 3  Bottom Copper  1 oz   0.035 mm
   Total thickness                1.600 mm ±10%

3. DRILL SCHEDULE
   PTH 0.30 mm : vias signal
   PTH 0.50 mm : vias power
   PTH 0.80 mm : component leads (R, C, LED)
   PTH 1.00 mm : connectors, terminal blocks
   NPTH 3.20 mm : 4x M3 mounting holes

4. MECHANICAL
   Mounting holes : 4x NPTH 3.2 mm, corners, 5 mm from edge
   Board outline  : rounded corners R2.0 mm
   Connector edges: J1 DC jack on left edge
                    J2/J3 motor terminals on right edge
                    J7 LCD header on bottom edge
                    J4/J5/J6 on bottom edge
   Height limit   : Top side 15 mm (LCD + Arduino)
                    Bottom side 5 mm

5. MARKINGS
   - Silkscreen: ref des for all components
   - Top silk : "AutoCarDealer v2" + version + date code
   - Polarity : D1/D2 cathode mark, C1/C2 "+" mark
   - Pin 1   : U1, U2, DS1, J7, J8, J9 pin 1 mark
   - Fiducials: 3x 1.0 mm on top side (for optional PCBA)

6. PANELIZATION (optional)
   - Panel size   : 2x2 array (200 x 160 mm)
   - Gap          : 5 mm V-score or 2 mm routed
   - Fiducials    : 4 global + 2 local per board

7. TEST & INSPECTION
   - Electrical test: 100% net continuity + isolation
   - AOI            : 100% top and bottom
   - X-ray          : Not required
   - Impedance test : Not required

8. RoHS / REACH
   - RoHS 2011/65/EU compliant
   - REACH SVHC < 0.1% w/w
   - Halogen-free: optional (specify if needed)

9. DELIVERY
   - Format   : Gerber X2 (RS-274X) + Excellon drill
   - Files    : see Section 4 (Gerber output list)
   - Quantity : 5 / 10 / 30 pcs
   - Lead time: standard

============================================================
