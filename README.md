# AutoCarDealer v2 — 第二代自动发牌机

基于 Arduino 的双电机自动发牌机。A 电机驱动转盘定位到玩家位置，B 电机发牌，
光电开关计数，16x2 LCD 显示状态，支持双红外遥控器操作。

---

## 1. 功能特性

- 支持 2~8 人，1~3 副牌，含/不含大小王
- 支持“剩余牌”扣除（每人固定发 N 张后停）
- 双红外遥控器（NEC 协议），运行中也可调整比分/停止/恢复
- LCD 实时显示：人数、副数、王、比分 X/Y、方向、已发/总数、状态字符
- 红/绿双色 LED 指示：停止=红，运行=绿，暂停=黄（红+绿）
- A 电机上电自动归位；支持手动校准
- 电机 A/B 超时、A 卡死保护，异常自动暂停
- 非阻塞 LED 闪烁，不阻塞主循环
- 可选：轻量 LCD 刷新、漏检补偿、每副暂停检查（见“编译开关”）

> 电机 A/B 的转向如与预期相反，交换 AO1/AO2 或 BO1/BO2 即可，无需改代码。

### 3.4 光电开关

代码使用 `INPUT_PULLUP`，**遮挡时输出 LOW**。常见槽型光耦（ITR9608）或红外对射模块均符合。
- 光电 A：A4，转盘码盘 16 边沿/圈
- 光电 B：A0，发牌通道出口

接线：VCC→5V，GND→GND，OUT→对应 Arduino 引脚。若模块输出为“遮挡高”，需在 OUT 与 Arduino 之间加反相器，或改用“遮挡低”型号。

### 3.5 红外接收

VS1838B：VCC→5V，GND→GND，OUT→A1。接收头前方避免被电机线遮挡，远离 PWM 走线。

## 4. 编译开关（`AutoCarDealer-v2.ino` 顶部）

| 宏 | 默认 | 说明 |
|---|---|---|
| `ENABLE_INFRA` | 1 | 启用第一遥控器 |
| `ENABLE_INFRA2` | 1 | 启用第二遥控器 |
| `ENABLE_KEYBOARD` | 0 | 启用串口命令（调试用） |
| `DEBUG` | 0 | 串口调试输出 |
| `IR_DEBUG` | 0 | 红外原始码输出 |
| `ENABLE_FAST_LCD` | 0 | 0=走 `updateDisplay()`；1=轻量刷新 |
| `ENABLE_MISS_COMPENSATION` | 0 | 0=卡牌慢可等；1=700ms 漏检补偿（会误判卡牌） |
| `ENABLE_DECK_CHECK_PAUSE` | 0 | 1=每副暂停“Check Deck!” |

### 4.1 关键参数

| 宏 | 推荐值 | 说明 |
|---|---|---|
| `MOTOR_A_SPEED` | 255 | A 转盘全速 |
| `MOTOR_B_SPEED` | **180** | B 发牌，180 实测 500+ 张 0 连发；190 起偶发 |
| `CARD_IGNORE_TIME` | 80 | 发牌后消隐窗口 |
| `PHOTO_A_DEBOUNCE` | 8 | A 码盘防抖 |
| `PHOTO_B_DEBOUNCE` | 10 | B 光电防抖 |
| `MOTOR_B_HARD_TIMEOUT` | 3000 | B 无牌 3 秒暂停兜底 |
| `MOTOR_A_TIMEOUT` | 1500 | A 转动超时 |
| `MOTOR_A_STUCK_TIME` | 500 | A 停滞检测 |
| `LOOP_DELAY` | 1 | 主循环延迟（ms） |

> **速度 vs 连发实测**：175~180 → 0 连发；190 → ~1.2%；235 → ~0.5~0.75%；255+最强制动 → ~0.7~1%。这是传感器物理采样极限，软件无法消除。要 0 连发请保持 180，或开启 `ENABLE_DECK_CHECK_PAUSE` 人工兜底。

## 6. 操作流程

1. 上电：LCD 显示 `Homing MotorA...`，A 转盘自动归位；完成后显示主界面。
2. 空闲设置：
   - `ch+`/`ch-` 调人数（2~8）
   - `prev` 调副数（1~3）
   - `next` 切换大小王
   - `0` 设置剩余牌（每人固定发 N 张后停）
   - `2` 切换旋转方向（切换后需按 `1` 重新校准 A）
3. 按 `play` 开始发牌。LCD 状态字符 `B`/`A` 交替，绿色 LED 亮。
4. 发牌中：
   - 按 `play` 暂停（黄灯），再按恢复
   - 按 `EQ` 停止
   - 按 5/6/7/8 调整比分
5. 发完：显示 `All Done!`，红灯亮，回到空闲。
6. 异常：`A Stuck` / `A Timeout` / `B Timeout` / `A Count Err`，按提示处理后按 `play` 恢复或 `EQ` 停止。

## 7. 常见问题

**Q1：屏幕偶发乱码？**
A：优先关闭 `ENABLE_DECK_CHECK_PAUSE`（改为 0，默认=0），减少电机启停与 LCD 全刷新重叠。仍偶发可把 `updateDisplay()` 全刷新里的“空格覆盖两行”改回 `lcd.clear()`，并在全刷新前后各加 `delay(5)`。硬件上确保 LCD 的 RW 接地、VCC-GND 加 100µF+0.1µF 去耦、电机与逻辑电源分离或单点接地。

**Q2：偶发连发两张？**
A：这是 B 电机停止惯性和传感器高速采样极限，不是软件 bug。把 `MOTOR_B_SPEED` 保持在 180（实测 500+ 张 0 连发）。若必须高速，开启 `ENABLE_DECK_CHECK_PAUSE=1`，每副暂停人工确认。纯软件在 ≥190 时无法保证 0 连发。

**Q3：卡牌慢时被误判转走？**
A：关闭 `ENABLE_MISS_COMPENSATION`（改为 0）。卡牌慢会正常等待检测，只有 3 秒硬超时才暂停。

**Q4：A 转盘位置偏了？**
A：按 `1` 重新校准 A。若切换过方向（`2`），必须重新校准。

**Q5：红外遥控无反应？**
A：开启 `IR_DEBUG=1` 看串口是否收到码。收不到检查 VS1838B 接线和 5V；收到但功能不对，把实际键码替换宏定义。

**Q5：LCD 对比度不对？**
A：调 10kΩ 电位器，直到字符清晰、无全黑/全白。
